Vaultlight is a tense top-down heist where you guide the thief Wick through the Gilded Reserve Museum at night. Evade patrolling guards with sweeping vision cones, bypass rotating cameras, and steal the glowing Sunstone Opal before the alarm hits 100%. Crouch to shrink your detection radius, throw noise coins to distract guards, and escape through the green-lit exit door.

## Run it

```sh
node serve.ts
```
